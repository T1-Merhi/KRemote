KRemote Installer - Quick Start

REQUIREMENTS:
1. Install Inno Setup from https://jrsoftware.org/isdl.php
2. Restart terminal after installation

BUILD OPTIONS:

Option 1 - PowerShell (Windows):
  cd C:\Users\Hussein.Merhi\source\T1-Merhi\KRemote
  .\Build-Installer.ps1

Option 2 - Batch File:
  cd C:\Users\Hussein.Merhi\source\T1-Merhi\KRemote
  Build-Installer.bat

Option 3 - Inno Setup GUI:
  Open KRemote-Installer.iss
  Click Build > Compile

OUTPUT:
  Location: Output\KRemote-Setup.exe
  Ready to distribute!

CUSTOMIZATION:
  Edit KRemote-Installer.iss to customize:
  - Version number
  - Publisher name
  - Installation directory
  - Shortcuts and tasks

See INSTALLER_SETUP.md for detailed instructions.
